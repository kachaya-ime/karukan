# Karukan IME Android 版 ユーザーマニュアル (Manual)

Karukan IME (Android版) の各種キーボードレイアウト（QWERTY、タブレット、ニコタッチ）、設定、辞書管理、および学習データバックアップ・復元についての利用マニュアルです。

---

## 1. キーボードレイアウトの種類と使い方

設定画面から、用途やデバイスに合わせて以下の3種類のソフトウェアキーボードレイアウトを切り替えて使用できます。

### ① QWERTY キーボード
スマートフォン等でのローマ字入力・英語入力に対応するQWERTY配列レイアウトです。
ワンタップで記号入力画面等に切り替えるトグル方式を採用しています。

- **主な機能キー**:
  - **Shiftキー (`⇧`)**: アルファベットの大文字入力やシフト面への切り替えを行います。
  - **記号切替キー (`@!?` ⇄ `ABC`)**: 1回タップで全ASCII記号入力画面へ遷移し、同じ位置のキーをもう1回タップすることで元の通常画面に戻ります。
  - **Ctrlキー (`Ctrl`)**: ショートカットやIMEコマンドをサポートします。
  - **言語切替キー (`あa`)**: 日本語入力モードと英語/直接入力モードをトグル切替します。
  - **絵文字キー (`😊`)**: 絵文字パレットを開きます。
  - **方向キー (`←` / `→`)**: カーソルを左右に移動します。

---

### ② タブレットレイアウト
タブレットや大型端末向けの、PCのフルキーボードに近いレイアウトです。
- **主な特徴**:
  - 独立した数字行（`1`〜`0`）、ファンクションキー（`Esc`, `Tab`）、各種ブラケット（`[`, `]`, `\`）が配置されています。
  - 十字矢印キー（`↑`, `↓`, `←`, `→`）、`Ctrl` キー、および絵文字キー (`😊`) が配置されています。

---

### ③ ニコタッチ入力 (Niko Touch)
2打鍵（1打目：行、2打目：列）の組み合わせによってひらがな・英数字・記号を入力するマトリクス入力方式です。

> **法的・仕様上の注記 (Notice)**: 本Androidフロントエンドにおいて実装・提供している「ニコタッチ方式」のキーボードレイアウトおよびマッピング仕様は、パナソニック株式会社（Panasonic）の携帯電話等で採用されていた「ニコタッチ」入力方式に基づいています。

#### 2打鍵の仕組み
1. **1打目（行の選択）**:
   - キーボード上の「あ (1)」「か (2)」「さ (3)」「た (4)」「な (5)」「は (6)」「ま (7)」「や (8)」「ら (9)」「わ (0)」のいずれかのキーをタップします。
2. **2打目（列の選択・文字確定）**:
   - 1打目を押すと、2打目のガイド（対応する10文字）に切り替わります。目的の文字が配置されている位置のキーをタップすると文字が入力されます。

#### 濁音・半濁音・小文字のトグル変換
- 入力された文字に対して、濁点（ﾞ）、半濁点（ﾟ）、または小文字（っ、ゃ、ゅ、ょ等）への変換が必要な場合は、トグルキー（`ﾞﾟ` キー）を押すことで清音 ⇄ 濁音 ⇄ 半濁音 ⇄ 小文字を順次切り替えることができます。

## 2. 学習データのバックアップと復元 (Backup & Restore)

Karukan IME は、変換学習によって蓄積された学習履歴（頻度・タイムスタンプを含む）を TSV形式（拡張子 `.txt`）のファイルとしてバックアップおよび復元する機能を備えています。

- **バックアップ（エクスポート）**:
  1. 設定画面を開きます (`Karukan IME 設定`)。
  2. 「学習データのバックアップ」をタップします。
  3. 保存先を指定すると、`karukan_learning_backup.txt` としてTSV形式で保存されます。
- **復元（リストア・インポート）**:
  1. 設定画面を開きます。
  2. 「学習データの復元」をタップします。
  3. 以前にバックアップした `.txt` ファイルを選択すると、内部学習辞書に復元され、ネイティブエンジンへ反映されます（カウントやタイムスタンプも保持されます）。

## 3. ユーザー辞書の管理
- 設定画面の「ユーザー辞書の管理」から、独自のユーザー辞書ファイル (`.txt`, `.bin`) の追加、有効/無効の切り替え、単語の個別追加・編集・削除を行えます。

## 4. キーボードショートカットとカスタムカスタマイズ設定

物理キーボードおよびソフトウェアキーボード接続時、以下のショートカットキーが利用できます。

- **F6 〜 F10**: ひらがな(F6)、全角カタカナ(F7)、半角カタカナ(F8)、全角英数(F9)、半角英数(F10) への未確定変換（F9/F10は連続押下で小文字/大文字/頭大文字トグル）
- **Ctrl + A / C / V / X / Z**: 全選択 / コピー / 貼り付け / 切り取り / Undo (元に戻す)
- **Ctrl + B / F / N / P**: カーソル左移動 / カーソル右移動 / 次候補 / 前候補
- **Ctrl + M / Enter**: 確定
- **Ctrl + G / Escape**: キャンセル
- **Ctrl + H / Backspace**: 前の1文字削除
- **Ctrl + 1 〜 9**: 番号指定による候補選択・確定
- **Ctrl + K**: カタカナ変換 / カタカナモード切替
- **Ctrl + L**: ライブ変換 ON/OFF トグル
- **Ctrl + I**: AI 候補ビューオープン
- **Ctrl + R**: 記号・日付ビューオープン
- **Ctrl + T**: 学習ソースビューオープン
- **Ctrl + J**: Chunk区切り・固定
- **Ctrl + Space**: 日本語 / 英語 モード切替
- **Shift + Space**: 全角スペース入力 / 入力時・変換時は前候補選択

### キーショートカットの自由カスタマイズ設定
設定画面の **「キーショートカットの設定」** から、各キーショートカットのアクションを自由にカスタマイズ・変更できます。
※誤操作防止のため、基本の編集キー・ナビゲーションキー（`Ctrl + A, B, C, F, N, P, V, X, Z`, `Ctrl + Space`）は固定状態となっています。

## 5. 記号・日付変換と便利機能

### 記号・日付ビュー (`Ctrl + R`)
「きょう」「いま」「あした」「にちじ」「かっこ」「やじるし」などの読みを入力した後に **`Ctrl + R`** を押すと、各種フォーマットの日付・時刻候補（`2026/03/31`, `2026年3月31日`, `令和8年3月31日`, `15:30` 等）や特殊記号・単漢字が先頭にまとめて表示され、ワンキーで選択・確定できます。

### ペア括弧確定時のカーソル自動移動
`「」`, `『』`, `（）`, `()`, `［］`, `[]`, `【】`, `｛｝`, `{}` などのペア括弧を確定（Enter）すると、自動的にカーソルが 1 文字左（括弧の中 `「|」`）へ移動します。確定後すぐに括弧内へ文字を入力開始できます。
※設定画面の「ペア括弧確定時にカーソルを括弧内に移動」から ON/OFF を切替可能です。

## 6. 物理キーボード接続時およびライブ変換の動作仕様

物理キーボード接続時にライブ変換機能が有効な場合の動作仕様は以下の通りです：

- **フローティング候補およびステータス追従表示**:
  - カーソル位置の近傍にリアルタイムの変換候補がフローティングポップアップとして常時表示され、文字入力のたびにポップアップが消えることなく、内部の候補一覧がスムーズにインプレース更新されます。
  - ステータス表示には、現在の入力かなに加え、元のローマ字（例: `(ローマ字: kanji)`）が併記されます。
- **候補ボックステーマ**:
  - 各候補ボタンは角丸（6dp）および灰色枠（ストローク）付きのボックスデザインを採用しており、選択中ハイライトの彩度を抑えた見やすい配色になっています。
  - 候補の（）で囲まれた説明部分（アノテーション）は 75% の縮小文字サイズで表示されます。
- **言語モード切替インジケーター (`jp` / `en`)**:
  - `Ctrl + Space` 等で日本語／英語モードを切り替えた際、カーソル位置に小型のポップアップで `"jp"` または `"en"` が一時表示され、約1.2秒後に自動でフェードアウト（オートディスミス）します。
- **フォーカス外れ時の安全処理**:
  - 入力フォーカスが外れたり、ウィンドウが非表示になったりした際には、ポップアップが自動的に消去され画面に残らないよう安全に管理されています。
